03

응답 설정

ChatGPT를 연결하면 모델과 저장된 설정을 불러옵니다.

캐릭터와 대화 기록은 Risu가 전달합니다. 상세도는 정확한 글자 수나 토큰 수를 제한하지 않습니다.

04

연결 테스트

저장된 설정으로 짧은 응답을 받아봅니다. 성공하면 Risu에서 대화를 시작하세요.

테스트에도 구독 사용량이 소모됩니다.

아직 테스트하지 않았습니다.
사용 범위와 연결 진단
  • 텍스트 대화와 스트리밍을 지원합니다. 대화 기록은 Risu가 관리합니다.
  • 한 번에 한 응답을 생성하며, 요청은 최대 180초 동안 처리합니다. 입력 한도는 2 MiB입니다.
  • temperature, top_p, penalty, seed, max_tokens 등은 적용되지 않습니다. 도구 호출·이미지 입력·구조화 출력·복수 생성은 지원하지 않습니다.
  • 구독 사용량 제한이 적용됩니다. 연결이 끊어졌다면 실행 터미널을 확인하고 브리지를 다시 실행하세요.
